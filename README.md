Разные варианты запуска:

## Генерация сертификатов ##

Генерация ssl-сертификатов. Если в папке sourcefiles/certbot/conf/live нет действующих сертификатов, сервис работать
не будет. Перед первым запуском эти сертификаты надо создать, и в дальнейшем регулярно обновлять. Делается это
командой

`$ run.sh stage generate` или `$ run.sh prod generate`

Для автоматизации надо добавить в крон регенерацию сертификатов.

`> 0 5 1 */2 *  run.sh generate`

## Обновление приложения ##

Обновляется только контейнер приложения, остальные сервисы не трогаются.

`$ run.sh stage update` или `$ run.sh prod update`

## Запуск и остановка ##

**prod:** 

Запускается контейнер с приложением effective-solution:latest, сервера redis и rabbitmq, аналитика и мониторинг. 
Наружу открыты только порты приложения и 3000 - порт для Grafana (TODO: посадить на отдельный домен, выдать сертификат)

`$ run.sh prod`

**stage:**

запускается контейнер с приложением effective-solution:dev, сервера redis и rabbitmq, аналитика и мониторинг.
Наружу открыты все порты сервисов, кроме grafana, чтобы можно было смотреть что происходит внутри сервисов.
Grafana не открыта, так как она доступна через nginx.

`$ run.sh stage`

**dev:**

Запускаются только сервера redis и rabbitmq
Рассчитывается, что приложение запускается разработчиком локально
Наружу открыты все порты redis и rabbitmq

`$ run.sh dev`
